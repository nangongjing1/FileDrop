用手机扫码直接打开
扫码会打开 IP 地址，不依赖 DNS，也不用在手机上输入网址。
1. 设备打不开客户端页面
· 先用「可用地址」中的 IP 地址测试，排除域名解析问题。
· 确认客户端与服务端在同一个 Wi-Fi / 局域网，且服务端没有连接 VPN。
· Windows 防火墙需放行 TCP 和 UDP 端口，控制台会自动尝试添加规则；若 UAC 被拒绝，请以管理员运行一次本程序。
2. 想用 filedrop.ng 访问
· 把客户端的 DNS 手动设置为服务端 IP(Android/iOS 在 WLAN 设置里改静态 DNS)。
· 或修改客户端 hosts，加入启动时控制台显示的那一行记录。
· 手机不能改 hosts，只能用改 DNS 或直接访问 IP 的方式。
3. 域名打不开
· 域名需要设备把 DNS 指向服务端，或在局域网 DHCP 里下发；否则会提示「找不到服务器」。
· 请在地址栏输入完整地址：http://filedrop.ng/(若被改成 https:// 请改回 http://)。
